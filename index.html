¿Cómo conecto la API real de Google Maps?

1 · Crea un proyecto en Google Cloud, activa Directions API, Distance Matrix API y Geocoding API, genera una key y pégala en Ajustes.
2 · Esta app la inyecta como https://maps.googleapis.com/maps/api/js?key=TU_KEY y usa DirectionsService.route — optimizeWaypoints:true.
3 · Sin key, todo funciona igual con Nominatim + OSRM — estimación vial real, sin costo.

Recargos por tipo de viaje — % sobre el combustible

Fórmula: combustible = km × consumo × precio. Recargo = % × combustible. Subtotal = combustible + recargo + gastos. Precio cliente = subtotal ÷ (1 − chofer%). El chofer se lleva ese % del precio cobrado.
